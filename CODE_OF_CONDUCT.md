# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short:

- Be respectful and assume good faith.
- Critique work, not people.
- Harassment of any kind is not tolerated.

This applies in issues, pull requests, discussions and any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainer through the contact on the maintainer's GitHub profile, or through the repository's private reporting form. Reports are handled confidentially. The enforcement guidelines are those of the Covenant.
